# Workflow

This project contains a Node.js backend built with Express and a React frontend.

## Project Structure

```
backend/  # Express API
frontend/ # React app
```

## Backend Setup (Node/Express)

1. `cd backend`
2. Run `npm install` to install dependencies.
3. Copy `.env.example` to `.env` and configure environment variables like `PORT`.
4. Start the server with `npm start`.

## Frontend Setup (React)

1. `cd frontend`
2. Run `npm install` to install dependencies.
3. Start the development server with `npm start`.

The backend requires a `.env` file with the environment variables needed for your API. Use `.env.example` as a template.
